# Font Organizer

A modern Python-based font organization tool for managing and curating font collections.

## Features

- 🔍 **Smart Font Detection** - Automatically discover fonts across your system
- 📁 **Intelligent Organization** - Sort and categorize fonts by various criteria
- 🔤 **Font Subsetting** - Extract specific character sets from fonts
- 📊 **Analysis Tools** - Examine font metrics and properties
- 🚀 **High Performance** - Efficient processing of large font collections

## Quick Start

```bash
# Install via pip
pip install font-organizer

# Basic usage
font-organizer organize ~/Fonts
```

## Why Font Organizer?

Managing large font collections can be challenging. Font Organizer helps you:

- **Eliminate duplicates** - Find and remove duplicate font files
- **Organize by metadata** - Sort fonts by family, style, weight, etc.
- **Create subsets** - Extract only the characters you need
- **Analyze collections** - Get insights into your font library
- **Automate workflows** - Batch process fonts with custom rules
